# 360°レビュー記録

PLATEAUの写真テクスチャと地表・景観のシェーダを適用したシーンを、Solが4回レビューしました。各回で通常高度の8方位、低高度の4方位、俯瞰、飛行中の静止画を確認しました。後半の2回では和田倉濠と芝生の近景、同じ時刻のフレアのオン・オフも比較しました。

| 回 | 確認と対応 |
| --- | --- |
| 1 | 手前の高層棟が駅舎を遮っていたため、行幸通りを通る軌道に変更。道路に航空写真を投影し、街路の標示と歩道の境界を再現。 |
| 2 | 丸の内駅舎の赤煉瓦と両ドームが見えることを確認。遠景の境界を深度フォグでなじませ、フレアの遮蔽判定を実時間で更新するように修正。 |
| 3 | 全周と終景で遠景が空へ連続することを確認。和田倉濠の水面を表示し、フレアのオン・オフの差を確認。濠で見えた波の格子を修正対象とした。 |
| 4 | 濠の水面に空と街並みを映し、波紋の位相を変えて格子を解消。駅舎、全周の遠景、フレアの見え方に目視上の劣化がないことを確認。 |

広場と芝生の近景には、元の航空写真の解像度に由来するぼけが残ります。低い位置からビル越しに駅舎を見る画角では、手前の建物による遮蔽が見られます。

## Blenderで制作した樹木とガラス

Blenderで制作した木の形状をThree.jsに読み込み、木漏れ日の空撮カットと窓の反射材質を追加しました。Solが2回レビューしました。

- 第1回は8方位の全周、低高度、木と窓の近接、空撮の5カットを確認。近景に混在する丸い樹冠、葉の切り替え時の縞、窓枠に広がる強い反射を修正対象にしました。
- 第2回は、複数方向から撮影した実葉の遠景用画像、葉の切り替え、窓面に絞った反射を再確認。固定カメラの2時刻で樹冠の葉と枝が風に動くことを確認しました。周回8方位、駅舎の両ドーム、遠景の霞を確認しました。
- 7.3秒の遠景では、一部の幹に距離切り替えに伴う点状の模様が残ります。

## 公開測量データの統合

Solが4回レビューしました。高い位置と低い位置の全周で地形の境界を確認し、主な指摘を次のように反映しました。

- 東京都オルソの白い欠測部を地理院の航空写真で補完し、護岸の急斜面に石色の材質を使いました。
- 駅南側の測量支持面に沿ってレール・まくらぎを作り、軌道の端と高さから路盤を再構成しました。駅の覆屋と軌道は別のBlenderコレクションで確認できます。
- 日本橋川の橋梁のカメラを高くし、高架と橋桁、川、両岸の取付部が見えるようにしました。
- Astraが元の位置と樹冠の外形を使ってPLATEAUの独立木98本をBlenderで作り直しました。Solは八重洲の接写と空撮の25.3秒・27.2秒で、横縞が消えて幹と葉の輪郭が見えることを確認しました。近景には路面の点状の白線と低い植栽の反復が残ります。
- 軌間はレールの頭部内側で1,067 mmになるように調整しました。最終試写の丸の内広場、両ドーム、日本橋川の橋桁、ガラスと護岸で、目立つ表示の劣化は見当たりませんでした。

Blenderで全863タイル、写真素材、軌道、7カットを保存し、再読込して全8方位を描画しました。

## 空撮で見つけた写真の誤投影

建物410タイルについて、元の建物IDと配信用GLBの三角形・画像・UVを照合しました。今回のLOD2には、全収録面に画像がある建物と、部分的に画像がある建物が混在します。[建物別の監査結果と再集計手順](building-textures.md)

- 12.1秒の新丸の内ビルディングと15.6秒の丸の内駅舎では、壁にヘリポートが写っていました。前者は同じ棟の上階の窓列、後者は同じ駅舎の反対側の赤煉瓦と窓を使って補修しました。屋上のヘリポートは水平面に残っています。
- 25.3秒の八重洲側ではグランルーフの垂直面に広場と通行人が写っていました。元の屋根形状を使い、東側のガラス、デッキ手すり、支柱を外観資料に基づく推定テクスチャで表現しました。手前の生垣は葉の大きさを揃え、上面・側面・端面に貼り直しました。[JR東日本建築設計の作品資料](https://www.jred.co.jp/projects/p007.html)
- 八重洲の都道405号では舗装と路面設備の高さを揃え、同じ場所に重なっていた道路の三角形を整理しました。区画線など10件、マンホール14件、側溝3件を元の測量形状で描き、白い点列になっていた「タクシー」の路面標示を復元しました。
- 日本橋川の高架では床版に航空写真の車と影が焼き付いていました。重なる両区の道路と橋梁の上面に同じ座標で舗装を貼り、測量形状の縁に沿って路側線を表現しました。桁、川面、低い横断橋は元の形状・材質を使用しています。
- 皇居外苑と丸の内駅前では、地面に写った樹冠を同じ区画の芝・舗装で補い、空中写真から位置と幅を推定した木を配置しました。追加した木の樹高と樹種は近似です。

[同じカメラで撮影した修正前後の比較](texture-repairs.jpg)

Solが全周の試写に加え、書き出したH.264 MP4の14時点を確認しました。八重洲は24〜28秒を毎秒8枚で照合し、道路の白い点列が消えて路面標示が連続して見えることを確認しました。Blender 5.2.2で保存ファイルを再読込し、3棟の2Kアトラス、全写真の同梱、863タイル、空撮7カットを確認しました。[MP4とBlenderの同一時刻の比較](native-film-materials.jpg)

## 大丸有22棟・丸の内二丁目ビル・東京駅周辺地下街

Astraが作成したモデルに素材を貼ったあと、Solが棟ごとの表示、全周8方位、地下街の断面と床・壁の接写を確認しました。都市全体はBlender Lab MCPで統合し、同じ22棟をThree.jsの空撮にも使用しました。

- 棟ごとに外装写真を切り出した時点で、元写真より暗く見える色変換を修正しました。対応する画素を再照合したときの色差の平均は8ビット換算で約0.10階調でした。これは外壁を部分補修する前の測定です。
- 大手町パークビルディングなどを補修した後、全22棟を一棟ずつ45度刻みで撮影しました。サウスタワーや三菱UFJ信託銀行本店ビルの壁に写ったヘリポートやファンなどを、同じ棟の窓列を使って補いました。補修したのは21棟の1,026三角形で、窓割りと明るさには推定を含みます。全176カットを再確認し、最後に星のや東京の暗い矩形とサウスタワーの窓列の継ぎ目を見直しました。
- 丸の内二丁目ビルでは、空撮の21～24秒で円形の屋上設備2基が画面に収まるようにカメラを調整しました。羽根と格子は接写用に再構成しています。
- 地下街では、元データで形状を持つ35の階グループと、天井の表示切替を確認しました。コンコースの接写で、生成した床・壁のタイルが目地の寸法と向きを保つことを確認しました。

配布するGLBを読み直し、22棟の60,709三角形と、写真のある47,552三角形を元データと照合しました。各棟が使う外装写真は計79枚で、棟をまたぐ画像の共有はありません。Blender 5.2.2で開き直した編集用ファイルには画像89枚、都市全体のファイルには画像617枚と空撮8カットが収録されています。どちらも画像をすべて埋め込んでいます。

最終MP4は1,185フレームをエラーなく復号しました。Solが8カットすべてを毎秒1枚、二丁目ビルの屋上を毎秒10枚、八重洲を毎秒8枚で確認し、23.9秒と27.2秒は1080p原寸でも設備と路面標示を確認しました。7か所のカット切替と、接写でのちらつきに追加の指摘はありませんでした。

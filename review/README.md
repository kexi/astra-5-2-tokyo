# 360°レビュー記録

PLATEAUの写真テクスチャと地表・景観のシェーダを適用したシーンを、Solが4回レビューしました。各回で通常高度の8方位、低高度の4方位、俯瞰、飛行中の静止画を確認しました。後半の2回では和田倉濠と芝生の近景、同じ時刻のフレアのオン・オフも比較しました。

| 回 | 確認と対応 |
| --- | --- |
| 1 | 手前の高層棟が駅舎を遮っていたため、行幸通りを通る軌道に変更。道路に航空写真を投影し、街路の標示と歩道の境界を再現。 |
| 2 | 丸の内駅舎の赤煉瓦と両ドームが見えることを確認。遠景の境界を深度フォグでなじませ、フレアの遮蔽判定を実時間で更新するように修正。 |
| 3 | 全周と終景で遠景が空へ連続することを確認。和田倉濠の水面を表示し、フレアのオン・オフの差を確認。濠で見えた波の格子を修正対象とした。 |
| 4 | 濠の水面に空と街並みを映し、波紋の位相を変えて格子を解消。駅舎、全周の遠景、フレアの見え方に目視上の劣化がないことを確認。 |

広場と芝生の近景には、元の航空写真の解像度に由来するぼけが残ります。低い位置からビル越しに駅舎を見る画角では、手前の建物による遮蔽が見られます。

## Blenderで制作した樹木とガラス

Blenderで制作した木の形状をThree.jsに読み込み、木漏れ日の空撮カットと窓の反射材質を追加しました。Solが2回レビューしました。

- 第1回は8方位の全周、低高度、木と窓の近接、空撮の5カットを確認。近景に混在する丸い樹冠、葉の切り替え時の縞、窓枠に広がる強い反射を修正対象にしました。
- 第2回は、複数方向から撮影した実葉の遠景用画像、葉の切り替え、窓面に絞った反射を再確認。固定カメラの2時刻で樹冠の葉と枝が風に動くことを確認しました。周回8方位、駅舎の両ドーム、遠景の霞を確認しました。
- 7.3秒の遠景では、一部の幹に距離切り替えに伴う点状の模様が残ります。

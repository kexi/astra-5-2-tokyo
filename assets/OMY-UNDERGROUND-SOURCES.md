# 東京駅周辺地下街 LOD4.0

実証では、2020年度屋内地図、東京都の公共的屋内空間データ、駅構内図・3D駅構内地図、2023年度測量の出入口座標を参照して地下街BIMを作成した。地上では、施設管理者から提供された丸の内ビルディング、新丸の内ビルディング、丸の内オアゾ、丸の内パークビル、常盤橋タワー、大手町タワー、KITTE丸の内の7棟を使用した。今回開いた公開ZIPの収録地物は地下街のみ。7棟の提供BIMと、三菱地所設計の別事例「大丸有22棟」のモデルは、この地下街GLBに含まれない。[実証技術検証レポート §3-2-3、pp.89–95、113](https://www.mlit.go.jp/plateau/file/libraries/doc/plateau_tech_doc_0075_ver01.pdf)・[22棟の事例資料](https://bim-design.com/uploads/Mitsubishi-Jisho-CaseStudy_4P_ja.pdf)

## 地理参照と検証

配布GMLの座標は EPSG:6697 の緯度・経度・標高順。高度は T.P. 基準で、入力範囲は −27.295～+6.3007 m。屋内地図の床面は JGD2011 の経度・緯度順。配布GMLをそのまま表示すると地下街の長軸が東西に延び、基準地図上の東京駅周辺通路と一致しない。地上の東京駅位置と整合させるため、寸法・左右関係を保持する回転と平行移動を水平面に適用した。

1. プロジェクト共通の原点（東経139.7661°、北緯35.68117°、楕円体高40.0 m）からの差を、東90,528 m/度、北110,953 m/度で換算する。
2. 東・北平面上で反時計回り79.2874287°回転し、東 −927.4664 m、北 −817.8099 m 平行移動する。高さは元データを保ち、プロジェクトのジオイド高36.7647 mを加えて原点の楕円体高を引き、接平面の曲率差を補正する。
3. GLB はメートル単位の X東・Y上・Z南。Blenderの標準 glTF インポータでは X東・Y北・Z上となる。モデルの横幅約1.19 km、南北長約1.93 km。行幸地下ギャラリーにある「TP+150」の床中央高はモデル上で約 −3.09 m。原点・ジオイド補正を戻すとおおむね T.P.+0.15 m となる。

屋内地図とGMLの床の輪郭を粗く重ねてから、隣接する2辺の長さと角度が近い角406組を対応付けた。332組を水平剛体変換の推定に使い、丸ノ内線東京駅・千代田線二重橋前駅・日比谷線日比谷駅の74組を推定から外して検証した。推定用の水平残差は中央値0.054 m・90パーセンタイル0.242 m。留保した74組は中央値0.045 m・90パーセンタイル0.380 m・最大4.058 m。日比谷線日比谷駅の留保点は1組のみ。参照図は実証でも原典に使われており、この値は図形間の一致度を示す。独立した現地測量での絶対精度と各地点の実地高さは未検証。駅・路線別の件数と誤差は [位置合わせの記録](../tools/omy-underground-alignment.json) にある。

## 形状・断面・表面

772,226個の入力ポリゴンを読み、内周のある90面は穴を保って三角形化した。面積が実質ゼロの727面を除外。ミリメートル単位で頂点をまとめ、同じ階・分類内で重複三角形を除いた。GLB の957,947三角形を174ノードに整理し、736室・47の施設別階グループに由来する形状を収める。階グループには各駅・通路の階名や基準レベルも含む。元の地物種別はノードの `extras.semantic`、表示区分は `extras.role`、元資料の階名は存在する場合に `extras.storeyName` に格納した。断面表示は天井・閉鎖面の `extras.cutawayHide` を使う。

元のGMLに CityGML Appearance、実写画像、実測仕上げの記載はない。床面には60 × 60 cmの石調タイル、壁面には60 × 30 cmの千鳥張りを仮定して生成した。寸法、目地、斑点、粗さ、色は表示用の推定である。床面の暖色、壁面の青緑、点字誘導材の黄色で分類を区別する。床・壁それぞれに、色・法線・粗さの256 × 256 px PNGをGLBに内包した。1.2 m周期の平面UVを共通原点から与え、隣接する同方向の面で目地をつなげている。

## 再生成

```sh
uv run tools/audit-omy-registration.py
uv run tools/prepare-omy-underground.py
```

既存の登録値を再推定して保存する場合は監査コマンドに `--write` を付ける。入手済みZIPは両コマンドの `--archive`、屋内地図ZIPは監査コマンドの `--indoor` で指定できる。入力ハッシュを検査し、変換後のハッシュ、範囲、分類別の情報を [地下街のメタデータ](omy-underground.json) に記録する。
